## 🚀 Quick Start Guide

### First-Time Users

1. Read [INSTALLATION.md](INSTALLATION.md) to install the application
2. Follow the setup wizard to create your account
3. Review [USER_GUIDE.md](USER_GUIDE.md) for basic operations
4. Set up your clinic profile and start adding patients

### Regular Users

1. Use [USER_GUIDE.md](USER_GUIDE.md) for reference
2. Follow backup recommendations in the guide
3. Contact support if you encounter issues

## 🔒 Security Information

- All data is stored locally on your device
- No data is transmitted to external servers
- You are responsible for data backups
- See [PRIVACY_POLICY.md](PRIVACY_POLICY.md) for details

## 📞 Support

If you need help:

1. Check the relevant documentation file
2. Review troubleshooting sections
3. Contact support: support@dentalimplant.com
4. Include your OS version and error messages

## 📱 Platform-Specific Information

### Windows Users
- See [INSTALLATION.md](INSTALLATION.md) for Windows-specific setup
- Data location: `C:\Users\YourName\AppData\Roaming\dental-implant\`

### macOS Users  
- See [INSTALLATION.md](INSTALLATION.md) for macOS-specific setup
- Data location: `~/Library/Application Support/dental-implant/`

## ⚠️ Important Notes

- **Backups are essential** - See USER_GUIDE for backup procedures
- **Password recovery** - Uses security question (no email recovery)
- **Data ownership** - You own and control all your data
- **Compliance** - You must follow local healthcare regulations
